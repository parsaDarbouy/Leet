# Parcel Tracking System (practice OA)

CodeSignal-style **4-level** class problem. Implement methods on `ParcelTrackingSystem` in each level’s `solution.py`, then run that level’s tests.

```bash
cd parcel_tracking/level_1
python3 -m unittest test_level_1.py -v
```

Same pattern for `level_2`, `level_3`, `level_4`.

Copy your previous `solution.py` forward when you start the next level; later levels keep every earlier method.
